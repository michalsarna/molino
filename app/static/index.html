Privacy & browser storage

Cookies
None. This app sets no cookies and has no accounts, analytics or tracking.
Local storage
Two items, theme and lang, saved only when you press the theme button or pick a language, so your choice survives a reload.
Your image
Sent to this server only when you generate a preview or a download, processed in memory for that request and never written to disk.
Third parties
None. All scripts and assets are served from this server; nothing is loaded from a CDN.
Server logs
Like any web server, the operator's server may log request metadata such as IP addresses for operation and security.
